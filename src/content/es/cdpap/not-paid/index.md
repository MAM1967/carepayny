Cuando PPL retiene un pago, PPL@Home muestra la hoja de horas como **"Pended"** (el pago está retenido). Al hacer clic en la palabra "Pended", aparece la razón. Las razones vienen de la propia lista de PPL.

## Las cinco razones más comunes

Cada una tiene su propia página:

1. [La inscripción no está terminada](/cdpap/not-paid/sign-up-not-finished/)
2. [Falta el I-9](/cdpap/not-paid/missing-i9/)
3. [No hay horas aprobadas registradas (sin autorización)](/cdpap/not-paid/no-authorization/)
4. [La hoja de horas llegó tarde o no se aprobó](/cdpap/not-paid/late-timesheet/)
5. [Le pagaron menos que las horas enviadas](/cdpap/not-paid/paid-less/)

## La lista completa de PPL, en palabras sencillas

| Lo que dice PPL@Home | Lo que significa |
| --- | --- |
| Provider is not Paperwork Complete | La inscripción del PA (asistente personal) no está terminada. |
| Provider must have SSN | No hay un número de Seguro Social registrado para el PA. |
| Provider is not PA for Consumer | La cuenta del PA no está conectada con la del consumidor (la persona que recibe el cuidado). |
| Consumer is not enrolled during Time Entry's Date of Service | El consumidor no estaba inscrito por completo en esa fecha. |
| Consumer is missing CIN/Medicaid ID/Member ID | Al registro de tiempo le falta el número de Medicaid del consumidor. |
| There is no authorization for the Consumer's Plan… | No hay horas aprobadas registradas para el plan de salud actual del consumidor. |
| There is no authorization for Time Entry's service code | El tiempo usó un código de servicio que no está aprobado para el consumidor. |
| Time Entry's Date of Service is not within Authorization From/To Date | La fecha de trabajo está fuera de las fechas aprobadas. |
| Time Entry's Units exceed remaining on Authorization | Las horas pasan de las horas aprobadas que quedan. |
| Time Entry's Date of Service is during a gap in Consumer's enrollment or eligibility | El consumidor no tenía cobertura en esa fecha. |
| Time Entry overlaps with… | El tiempo se cruza con otro registro: uno del mismo PA, de otro PA o de otro consumidor. |
| Provider has already submitted a time entry for this time, under a different Service Code | El mismo tiempo se envió dos veces con dos códigos. |
| No Rate found | El código de servicio no existe. |
| Units cannot be zero | La hoja de horas estaba en blanco. |
| Consumer is deceased on Date of Service | Los registros de PPL muestran que el consumidor murió en esa fecha. |

Para muchas de estas razones, la lista de PPL dice que el registro de tiempo se puede corregir y enviar otra vez. Cuando falta una autorización, PPL dice que el tiempo se paga en la siguiente nómina después de que se arregla el problema.
