When PPL holds a payment, PPL@Home shows the timesheet as **"Pended."** Clicking the word "Pended" shows the reason. The reasons come from PPL's own list.

## The five most common reasons

Each has its own page:

1. [Sign-up is not finished](/cdpap/not-paid/sign-up-not-finished/)
2. [The I-9 is missing](/cdpap/not-paid/missing-i9/)
3. [No approved hours on file (no authorization)](/cdpap/not-paid/no-authorization/)
4. [The timesheet was late or not approved](/cdpap/not-paid/late-timesheet/)
5. [Paid less than the hours sent in](/cdpap/not-paid/paid-less/)

## PPL's full list, in plain English

| What PPL@Home says | What it means |
| --- | --- |
| Provider is not Paperwork Complete | The PA's sign-up is not finished. |
| Provider must have SSN | No Social Security number is on file for the PA. |
| Provider is not PA for Consumer | The PA's account is not linked to the consumer. |
| Consumer is not enrolled during Time Entry's Date of Service | The consumer was not fully signed up on that date. |
| Consumer is missing CIN/Medicaid ID/Member ID | The time entry is missing the consumer's Medicaid number. |
| There is no authorization for the Consumer's Plan… | No approved hours are on file for the consumer's current health plan. |
| There is no authorization for Time Entry's service code | The time used a service code the consumer is not approved for. |
| Time Entry's Date of Service is not within Authorization From/To Date | The work date is outside the approved dates. |
| Time Entry's Units exceed remaining on Authorization | The hours go past the approved hours left. |
| Time Entry's Date of Service is during a gap in Consumer's enrollment or eligibility | The consumer was not covered on that date. |
| Time Entry overlaps with… | The time overlaps with another entry: the PA's own, another PA's, or one for another consumer. |
| Provider has already submitted a time entry for this time, under a different Service Code | The same time was sent in twice under two codes. |
| No Rate found | The service code does not exist. |
| Units cannot be zero | The timesheet was blank. |
| Consumer is deceased on Date of Service | PPL's records show the consumer died on that date. |

For many of these reasons, PPL's list says the time entry can be corrected and sent in again. For a missing authorization, PPL says the time is paid in the next payroll after the problem is fixed.
