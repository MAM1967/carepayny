Когда PPL задерживает выплату, PPL@Home показывает табель со статусом **«Pended»** (выплата задержана). Если нажать на слово «Pended», видна причина. Причины взяты из собственного списка PPL.

## Пять самых частых причин

Для каждой есть своя страница:

1. [Регистрация не закончена](/cdpap/not-paid/sign-up-not-finished/)
2. [Нет формы I-9](/cdpap/not-paid/missing-i9/)
3. [Нет одобренных часов (нет разрешения на услуги)](/cdpap/not-paid/no-authorization/)
4. [Табель отправлен поздно или не одобрен](/cdpap/not-paid/late-timesheet/)
5. [Оплачено меньше, чем отправлено часов](/cdpap/not-paid/paid-less/)

## Полный список PPL простым языком

| Что пишет PPL@Home | Что это значит |
| --- | --- |
| Provider is not Paperwork Complete | Регистрация PA (личного помощника) не закончена. |
| Provider must have SSN | В записях нет номера социального обеспечения (Social Security, SSN) PA. |
| Provider is not PA for Consumer | Учётная запись PA не связана с получателем ухода. |
| Consumer is not enrolled during Time Entry's Date of Service | В эту дату получатель ухода ещё не закончил регистрацию. |
| Consumer is missing CIN/Medicaid ID/Member ID | В записи времени нет номера Medicaid (Медикейд) получателя ухода. |
| There is no authorization for the Consumer's Plan… | Для текущего медицинского плана получателя ухода нет одобренных часов. |
| There is no authorization for Time Entry's service code | Время записано под кодом услуги, который получателю ухода не одобрен. |
| Time Entry's Date of Service is not within Authorization From/To Date | Дата работы не входит в одобренные даты. |
| Time Entry's Units exceed remaining on Authorization | Часов больше, чем осталось одобренных часов. |
| Time Entry's Date of Service is during a gap in Consumer's enrollment or eligibility | В эту дату у получателя ухода не было покрытия. |
| Time Entry overlaps with… | Время совпадает с другой записью: другой записью этого же PA, записью другого PA или записью для другого получателя ухода. |
| Provider has already submitted a time entry for this time, under a different Service Code | Одно и то же время отправлено дважды под двумя кодами. |
| No Rate found | Такого кода услуги нет. |
| Units cannot be zero | Табель был пустой. |
| Consumer is deceased on Date of Service | По записям PPL, получатель ухода умер в эту дату. |

Для многих из этих причин в списке PPL сказано, что запись времени можно исправить и отправить снова. Если нет разрешения на услуги, PPL говорит, что время оплатят в следующую выплату после того, как проблему исправят.
