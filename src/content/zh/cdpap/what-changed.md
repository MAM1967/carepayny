最新的在最前面。每一条的资料来源都列在本页底部。

| 日期 | 有什么变化 |
| --- | --- |
| 2027年1月1日（即将生效） | 居家护理员的州最低工资提高：纽约市、长岛和 Westchester 是 {{2027.min.nyc}}，州内其他地区是 {{2027.min.rest}}。一般最低工资不变。更多内容：[您在 CDPAP 的工资标准](/cdpap/pay-rate/)。 |
| 2026年11月10日 | 一位联邦法官给予下州地区 PA（个人助理）的1.62亿美元 PPL 和解最终批准。更多内容：[PPL 诉讼和解](/cdpap/ppl-settlement/)。 |
| 2026年7月22日 | 卫生厅发布 MLTC 政策 26.02。PPL 会每两个星期把工作时间很长的 PA 报告给各健康计划。 |
| 2026年7月21日 | 和解通知用电邮和短信发给下州地区的 PA。 |
| 2026年7月1日 | 一位联邦法官给予 PPL 和解初步批准。 |
| 2026年5月27日 | 有些新 PA 开始由 The IMA Group 做健康检查，而不是 Mobile Health。 |
| 2026年5月1日 | 下州地区 PA 的新带薪病假政策开始。下州地区兼职 PA 以及没有参加 PPL 健康计划的下州地区 PA，工资平等的钱存入 401(a)。 |
| 2026年4月30日 | PPL 的 MEC（BasicWellness）健康计划和 Flex Card 计划结束。 |
| 2026年3月31日 | 2025年开始工作的 PA 完成 PPL 规定培训的截止日期。 |
| 2026年2月22日 | 纽约市的 PA 开始每年有32小时无薪病假。 |
| 2026年1月1日 | 所有 PA 每小时加薪 $0.55。PPL 的新基本工资标准开始。更多内容：[您在 CDPAP 的工资标准](/cdpap/pay-rate/)。 |
| 2025年9月1日 | 最低需求要求开始适用于21岁或以上人士的新评估和重新评估。 |
| 2025年4月1日 | PPL 成为纽约唯一可以给 CDPAP 工作人员发工资的公司。 |
