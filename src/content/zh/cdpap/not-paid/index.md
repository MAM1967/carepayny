PPL 暂时扣住一笔付款时，PPL@Home（PPL 的网站）会把工时表显示为“**Pended**”（付款暂时扣住）。点击“Pended”这个词，就会显示原因。这些原因来自 PPL 自己的列表。

## 五个最常见的原因

每个原因都有自己的页面：

1. [注册没有完成](/cdpap/not-paid/sign-up-not-finished/)
2. [缺少 I-9](/cdpap/not-paid/missing-i9/)
3. [没有批准的时数记录（没有服务授权）](/cdpap/not-paid/no-authorization/)
4. [工时表迟交或没有被批准](/cdpap/not-paid/late-timesheet/)
5. [付的工资比提交的时数少](/cdpap/not-paid/paid-less/)

## PPL 的完整列表，用浅白的话说明

| PPL@Home 上写的 | 意思 |
| --- | --- |
| Provider is not Paperwork Complete | PA（个人助理）的注册没有完成。 |
| Provider must have SSN | 记录上没有 PA 的社会安全号码（SSN）。 |
| Provider is not PA for Consumer | PA 的账户没有和受照顾者（CDPAP 中称为“消费者”，即接受照顾的人）关联。 |
| Consumer is not enrolled during Time Entry's Date of Service | 在那一天，受照顾者还没有完成注册。 |
| Consumer is missing CIN/Medicaid ID/Member ID | 这笔工时记录缺少受照顾者的 Medicaid（医疗补助，常称“白卡”）号码。 |
| There is no authorization for the Consumer's Plan… | 受照顾者目前的健康计划没有批准的时数记录。 |
| There is no authorization for Time Entry's service code | 工时用了受照顾者没有被批准的服务代码。 |
| Time Entry's Date of Service is not within Authorization From/To Date | 工作日期不在批准的日期之内。 |
| Time Entry's Units exceed remaining on Authorization | 时数超过了剩下的批准时数。 |
| Time Entry's Date of Service is during a gap in Consumer's enrollment or eligibility | 在那一天，受照顾者没有保障。 |
| Time Entry overlaps with… | 这段时间和另一笔记录重叠：可能是 PA 自己的、另一位 PA 的，或者是给另一位受照顾者的。 |
| Provider has already submitted a time entry for this time, under a different Service Code | 同一段时间用两个代码提交了两次。 |
| No Rate found | 这个服务代码不存在。 |
| Units cannot be zero | 工时表是空白的。 |
| Consumer is deceased on Date of Service | PPL 的记录显示受照顾者在那一天去世。 |

对很多这些原因，PPL 的列表说工时记录可以更正后重新提交。对于缺少服务授权的情况，PPL 说问题解决后，工时会在下一次发薪时付。
