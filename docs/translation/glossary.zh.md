# 翻译词汇表：中文（简体，zh-Hans）

本文件与 `glossary.md` 配套使用：`glossary.md` 列出英文词汇和含义，本文件列出批准的中文译法。

## 不翻译的词

以下词语在中文页面中保持英文原样：

CarePayNY · PPL · PPL@Home · CDPAP · Time4Care · I-9 · W-4 · IT-2104-I · EVV · MLTC · CIN · 401(a) · 401(k) · SSL · Atticus Administration · Calderon v. Public Partnerships, LLC

每个页面第一次出现时，可以在后面用括号加一句简短的中文说明。

机构、案件和应用名称（The Legal Aid Society、NY State of Health、Atticus Administration、Katz Banks Kumin、amNewYork Law、Time4Care、PPL@Home 等）也保持英文，第一次出现时可加中文说明。

## 批准的译法

| English | 中文（简体） | Notes |
| --- | --- | --- |
| home care worker | 居家护理人员 | 泛指护理员和照顾者 |
| home care aide | 居家护理员 | 法律用语，指适用居家护理最低工资的工作 |
| personal assistant (PA) | 个人助理（PA） | CDPAP 中领工资的照顾者。第一次出现写“个人助理（PA）”，之后可只写“PA” |
| consumer | 受照顾者 | CDPAP 中接受照顾的人。每页第一次出现写“受照顾者（CDPAP 中称为“消费者”，即接受照顾的人）”。只有引用 PPL 或州政府的名称时才用“消费者”（例如项目全名“消费者主导个人助理项目”） |
| designated representative | 指定代表 | 替受照顾者做 CDPAP 决定的人 |
| health plan | 健康计划 | 受照顾者的 Medicaid 计划 |
| local social services office | 地方社会服务办公室 | 可以批准护理时数的县办公室。LDSS（Local Department of Social Services）也写作“地方社会服务办公室”。不要简写成“社会服务办公室”或“社会服务局” |
| service authorization | 服务授权 | 对护理时数、服务代码和日期的批准 |
| approved hours | 批准的时数 | 健康计划批准的护理时数 |
| fiscal intermediary | 财务中介 | 负责 CDPAP 发薪的公司。“Statewide Fiscal Intermediary”写作“全州财务中介（Statewide Fiscal Intermediary）” |
| minimum wage | 最低工资 | 法律允许的最低时薪 |
| base pay / base rate | 基本工资 / 基本时薪 | 未加其他款项之前的时薪 |
| wage parity | 工资平价 | 每页第一次出现写“工资平价（Wage Parity，纽约市、拿骚县、萨福克县和威彻斯特县的 Medicaid 居家护理最低总薪酬规定）”。法律名称写作“工资平价法（Wage Parity Law）”。不要用“工资平等”。“wage parity employees”写作“工资平价规定涵盖的员工” |
| overtime | 加班费 | 每周超过 40 小时的部分按更高工资计算；指加班时间时可写“加班” |
| time and a half | 1.5倍工资 | 正常时薪的 1.5 倍 |
| pay period | 发薪周期 | 一次工资所包括的日子 |
| payday | 发薪日 | 工资到账的日子 |
| pay stub | 工资单 | 一次工资的纸质或网上记录 |
| timesheet | 工时表 | 工作时间的记录 |
| clock in / clock out | 上班打卡 / 下班打卡 | 在应用程序里或用电话开始和结束一个班 |
| direct deposit | 直接存款 | 工资直接存入银行账户 |
| paper check | 纸质支票 | 用邮寄支票的方式发工资 |
| live-in (per-diem) | 同住（live-in，按日计酬） | PA 和受照顾者住在一起的服务。第一次出现可写“同住（live-in，PA 和受照顾者住在一起，按日计酬）”。不用“住家”（容易误解为“待在家里”） |
| 24-hour shift | 24小时班 | 一整天的班 |
| paid sick leave | 带薪病假 | 生病时可以休息并照常领工资 |
| holiday pay | 假日工资 | 在节假日工作的额外工资 |
| health check (health assessment) | 健康检查 | 新 PA 必须做的体检 |
| sign-up (registration) | 注册 | 成为 PPL 的员工 |
| "Paperwork Complete" | “Paperwork Complete”（所有文件已完成） | 保留英文并加引号；每页第一次出现时加括号说明 |
| "Pended" | “Pended”（付款暂时扣住） | 保留英文并加引号；每页第一次出现时加括号说明。动词 hold（a payment）写作“暂时扣住”。不要和 PA 的“暂停状态”（on hold）混用 |
| wage claim | 工资索赔 | 向劳工厅投诉被欠工资 |
| settlement | 和解 | 以付款结束诉讼的协议 |
| class member | 集体诉讼成员 | 和解所包括的人 |
| Department of Labor | 劳工厅 | 全称“纽约州劳工厅” |
| Department of Health | 卫生厅 | 全称“纽约州卫生厅” |
| Medicaid | Medicaid（医疗补助，常称“白卡”） | 保留英文 Medicaid；每页第一次出现时写“Medicaid（医疗补助，常称“白卡”）”，之后只写“Medicaid”。不要用“联邦” |
| domestic worker | 家务工作者 | 纽约劳工法用语，指家庭雇来在家里工作的人 |
| casual basis | 临时性（工作） | 偶尔才做、不是固定的工作 |
| benefit portion | 福利部分 | 工资平价中可以用福利或现金支付的部分 |
| 13-hour rule | 13小时规定 | |
| exemption | 豁免 | 某项法律不适用的规定 |
| third-party employer | 第三方雇主 | 家庭以外的雇主，例如护理机构 |
