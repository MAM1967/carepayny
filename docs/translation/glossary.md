# Translation glossary

Use these terms exactly in every translation. Update this file **before** translating a page with a new term.
The 3 language columns get filled in once the owner picks the languages (PRD, "Decisions for the owner").

## Never translate

Keep these exactly as written, in every language:

CarePayNY · PPL · PPL@Home · CDPAP · Time4Care · I-9 · W-4 · IT-2104-I · EVV · MLTC · CIN · 401(a) · 401(k) · SSL · Atticus Administration · Calderon v. Public Partnerships, LLC

On first use on a page, a short explanation in the target language can follow the term in parentheses.
