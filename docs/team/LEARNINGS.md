# Learnings

- 2026-11-24 · health.ny.gov blocks automated fetches; the healthweb-back.health.ny.gov mirror usually loads. Cite the www page when a search returns it.
- 2026-11-24 · Have a second agent re-read the exact regulation text for any "must" sentence. The background-check page first said supervision was every other week; 10 NYCRR § 402.4(b)(2)(ii) says weekly. Translators' back-translation flagged the ambiguity first.
- 2026-11-24 · A new English guide page takes its section's translations offline until every language has it (publishedLocales). Ship English and translations in the same PR.
- 2026-11-24 · This session cannot delete GitHub branches (git push --delete returns 403). The repo setting "Automatically delete head branches" handles it.
